# 别再问我 · Don't Ask Me Again

一个以 **Mac 桌面端**为首发平台的本地个人资料助手。用户保存一次个人信息，在填写申请时，由本地模型协助识别字段、查找资料并生成填写方案，用户审核后再填写。

**当前仓库阶段：产品与技术规划，仅包含文档，尚未创建 App 工程或实现任何功能。**

## 项目方向

- **当前平台：macOS。** 首版只规划 Mac 原生客户端及配套的 Mac Safari 扩展。
- **本地数据与本地推理。** 核心功能不依赖开发者账户、云端资料库或远程模型服务。
- **事实可追溯。** 每个答案应能定位到资料来源、有效日期及用户确认状态。
- **用户控制信息披露。** 在资料写入网页前审核目标网站与具体字段；最终提交由用户操作。
- **商业闭源产品。** 以 Mac App Store 分发为目标，具体上架要求在发布阶段核对。

本地处理指资料存储、检索和推理在设备上完成。用户授权填写后，目标网站可以读取所填写的信息；这与是否点击“提交”是两个不同的边界。

## Mac MVP 范围

1. 本地资料库：管理身份资料、联系方式、地址历史、教育和工作经历。
2. 文档导入：在 Mac 上导入 PDF 或图片，提取候选资料并由用户确认入库。
3. 本地检索：按问题查找资料，展示依据，提示缺失、冲突和过期信息。
4. 填写预览：逐字段展示目标、候选答案与来源，允许修改或取消。
5. Safari 辅助填写：在获授权的单页标准 HTML 表单中填写已确认的字段。
6. 本地数据管理：锁定、删除、加密备份及恢复。

以上均为计划功能。首版不包含无人值守申请、自动提交、自动签名、验证码处理或任意第三方 App 控制。
