# Mac 路线图与 Future Work

## 当前阶段：仅文档

本次交付是产品范围、拟议架构和路线图。仓库尚无 App 工程、可运行版本或已验证功能。下列里程碑均为后续计划，不在本步骤执行，也不代表已承诺发布时间。

Mac 首版独立完成本地资料管理、检索、审核与 Safari 辅助填写，不依赖手机端或跨设备同步。

## 后续 Mac 里程碑

| 阶段 | 交付目标 | 完成条件 |
| --- | --- | --- |
| M0：技术验证与范围冻结 | 确定最低 macOS 版本、设备要求、本地模型、加密存储和扩展通信方案 | 验证模型不可用路径、沙盒可行性、备份恢复及页面授权绑定；记录决定和限制 |
| M1：Mac 本地资料库 | 手动录入、来源与时间线、加密存储、锁定、删除和备份恢复 | 断网完成资料管理；恢复到全新资料库后数据一致 |
| M2：本地导入与检索 | PDF / 图片解析、待确认事实、本地问答和冲突提示 | 查询可追溯；未知信息不编造；模型不可用仍可手动使用 |
| M3：Safari 辅助填写 | 字段提取、填写预览、单次授权与标准单页表单填写 | 达到产品范围中的正确率、覆盖率与误披露验收目标；不执行提交 |
| M4：Mac 发布准备 | 兼容性清单、隐私说明、数据迁移、签名、商店素材与发布验证 | 在声明支持的 Mac 环境复验；完成适用的分发检查，另行推进上架 |

M1 依赖 M0；M2 和 M3 依赖资料库与权限边界稳定。M4 以完整 Mac 工作流通过验收为前提。首版不以增加平台数量作为完成标准。

## 最小验证场景

使用合成个人资料建立一份包含身份、地址、教育、工作经历的资料库，再对一份至少 30 个字段的单页申请表执行完整流程：

1. 导入并确认资料，包含至少一处冲突、一项过期信息和一个时间线缺口。
2. 本地检索并查看来源，确认未知事实不会被补造。
3. 生成填写预览，用户修改或排除部分字段后授权。
4. 填写获批项目，统计正确率、覆盖率、节省时间与人工修改次数。
5. 检查取消、锁定、导航、字段变化、跨来源 frame 和恶意页面输入是否阻止越权披露。
6. 导出加密备份并在全新资料库中恢复。

实际指标与兼容性必须等实现后测量；当前没有准确率、性能或安全性实测结论。

## Future Work

以下方向不属于 Mac 首版，也不作为本次开发任务。是否启动取决于 Mac 工作流验证结果与用户需求，不预设日期或优先顺序。

### iOS / iPadOS 客户端

- 手机或平板上的资料查看、管理与解锁。
- 使用手机相机扫描证件、图片和文件，再经用户确认入库。
- 审核 Mac 发起的填写请求并提供授权；需要独立设计设备身份与授权有效期。
- 在系统允许范围内提供移动 Safari 轻量填写，单独验证能力和交互限制。

启动移动端工作前重新评估系统 API、权限、交互和分发要求。不假设移动端能直接复用 Mac 执行器，也不承诺任意第三方 App 自动操作。

### 跨设备数据与授权

- 用户控制的加密文件迁移、局域网配对或设备直连。
- 可选的端到端加密同步，另行决定是否使用任何托管基础设施。
- 设备加入与撤销、密钥恢复、冲突合并和跨设备授权协议。

这些能力均需单独评估。Mac 首版不接入 iCloud 同步、不建立配对服务，也不要求用户拥有另一台 Apple 设备。

### 更复杂的 Mac 申请辅助

- 多页面表单、进度保存与失败恢复。
- 经单独授权的附件上传与更复杂的字段控件。
- 用户审核的长文本草稿与申请材料复用。
- 其他浏览器扩展，以及经过验证的本地模型替代后端。

后续扩展仍需保留来源追踪、最小授权及用户对信息披露的控制；自动提交和法律声明授权需要独立产品决策。
