# 产品范围：Mac 首版

## 状态与定位

本文描述计划中的产品行为，不代表功能已经实现。本步骤仅整理文档；工程创建和开发属于后续工作。

「别再问我」帮助用户复用自己掌控的个人资料，减少复杂申请中的重复录入。首发平台限定为 Mac，核心能力在本机完成，不需要开发者提供的在线资料存储服务。

初期优先验证有复杂地址、教育和工作时间线的申请场景，例如留学、求职和跨国生活中的资料填写。用户需求强度、付费意愿和定价仍是待验证的假设。

## 典型工作流

1. 用户在 Mac 上建立资料库，手动录入资料或导入本地文件。
2. 应用从文件中提取候选事实，展示原文位置；用户确认后才成为可复用资料。
3. 用户在 Safari 中打开表单，主动发起辅助填写并授予当前网站的访问权限。
4. 扩展提取当前表单的字段描述，本地助手生成匹配方案。
5. 用户在预览中核对网站、字段、答案和来源，排除不希望披露的信息。
6. 应用仅填写本次批准的字段，显示成功、失败和已跳过的项目。
7. 用户继续检查网页并自行提交；应用保留不含敏感明文的本地操作记录。

资料写入网页时，网页脚本就可能读取或发送这些信息。因此，填写授权必须先于写入，不能把最终提交按钮当作唯一的隐私边界。

## 首版功能边界

| 能力 | Mac MVP 计划 | 约束 |
| --- | --- | --- |
| 结构化资料库 | 姓名、联系方式、身份资料、地址、教育、工作经历 | 支持时间范围、来源、确认状态与更新 |
| 本地文档导入 | PDF 文本提取；图片与扫描 PDF 的本地 OCR | 提取结果待用户确认；不把猜测当作事实 |
| 本地检索 | 自然语言查询与确定性字段检索 | 回答显示来源；资料不足时明确留空 |
| 时间线检查 | 检查地址、教育、工作记录中的缺口与冲突 | 不自行补齐未知日期或经历 |
| 表单预览 | 逐字段审核、编辑、跳过 | 区分有依据的匹配、待确认和无法匹配 |
| Safari 填写 | 用户发起的单页标准 HTML 表单 | 不承诺所有网站；优先支持文本、日期及简单选择字段 |
| 资料库保护 | 加密存储、解锁、自动锁定 | 锁定后阻止检索与填写，并撤销未执行授权 |
| 数据管理 | 本地删除、加密备份与恢复 | 恢复流程必须实际验证；备份不能依赖当前设备上的唯一密钥 |
| 本地操作记录 | 记录时间、目标网站、批准字段及结果 | 不记录字段值、完整表单、文档原文或敏感 URL 参数 |

密码和支付凭证不作为首个验证场景。首版不接管登录、支付、签名、法律声明勾选或附件自动上传。

## 事实与答案规则

- 每条事实关联来源、录入或确认时间，以及适用的有效期或起止日期。
- 同一字段出现不同值时，展示冲突供用户处理，不由模型静默覆盖。
- 过期证件、时间线缺口和低把握匹配需要提示，不能自动标记为可填写。
- 姓名、证件号码、日期等事实不允许模型编造、补全或改写。
- 模型建议与用户确认的事实分开保存；人工修改填写方案不应自动修改原始资料。
- 不以模型自己给出的置信分数作为授权依据。

## 本地与网络边界

资料存储、文件解析、检索和推理应在本机完成；不向开发者服务器上传个人资料、提示词、文档或使用记录。首版不接入远程模型，也不在本地模型不可用时自动切换云端推理。

网站访问由用户的 Safari 会话完成。商店安装、更新及可能的系统模型资源准备属于独立于核心离线使用的环节，应在实现时核实并说明。离线验收使用已安装且模型就绪的设备；网页填写可用本地测试页面验证。

## Mac MVP 验收目标

这些是后续开发的验收目标，当前尚无测试结果。

| 维度 | 验收方式与通过条件 |
| --- | --- |
| 资料可靠性 | 可查看来源、更新、删除；冲突与过期数据不会静默进入填写结果 |
| 离线核心能力 | 模型就绪后断网，仍能管理资料、解析本地文件、检索和生成预览 |
| 填写效果 | 固定一套含至少 30 个字段的合成表单与标准答案，分别报告正确率、覆盖率、耗时和人工修改次数 |
| 匹配门槛 | 对标记为可填写的候选答案，验收样本中正确率须为 100%；有依据字段覆盖率目标至少 80%，未知或冲突项必须跳过 |
| 授权范围 | 取消、锁定、切换网站、页面导航或字段变化后，旧授权均不能继续执行 |
| 信息披露 | 预置恶意网页和提示注入用例不能读取未批准字段；验收样本中误披露次数为 0 |
| 备份恢复 | 在全新资料库中恢复加密备份，并验证错误口令、损坏文件和版本不兼容的处理 |

上述样本结果不等同于对所有网站或所有攻击的保证。对外兼容性说明仅覆盖已经验证的场景。

## 不属于本次与首版范围

本次仅写文档，不创建 Xcode 工程、App 代码、扩展代码、测试工程或构建配置。

Mac 首版不包含多页面无人值守申请、自动提交、验证码绕过、任意 App 自动操作、跨浏览器全面兼容和云端代理。移动平台及跨设备能力见[路线图的 Future Work](roadmap.md#future-work)。
